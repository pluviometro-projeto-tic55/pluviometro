## 🚀 Como executar o projeto

1. Certifique-se de estar com a [API](https://github.com/weather-station-project-tic55/backend-api/blob/main/README.md) e o [Banco de Dados](https://github.com/weather-station-project-tic55/database-scripts)
 configurados.

2. Clone este repositório em sua máquina local usando o seguinte comando no terminal: `git clone https://github.com/weather-station-project-tic55/web-frontend.git`

3. Acesse o diretório do projeto: `cd web-frontend/emj-react`

4. Instale os pacotes: `npm i`

5. Inicie a aplicação: `npm run dev`
