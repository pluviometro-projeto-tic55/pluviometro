# weather-station
Low budget weather station for schools with the purpose of teaching metereology and spreading awareness on the consequences of climate change.

All the code here goes into a Raspberry Pi board to receive data from sensors to then transmit that data to a database.

-------------------------------------------------------------------------------------------------------------------------------------------------------------

Estação meteorológica de baixo custo para escolas com o propósito de ensinar meteorologia e concientizar sobre as consequências das mudanças climáticas.

Todo o código aqui vai em uma placa Raspberry Pi para receber dados de sensores e transmiti-los para um banco de dados.
